# Forge Device
A small distraction-free device that can fit into your pocket, providing easy access to the time, a stopwatch, a timer, and more...

## Basic Summary
This project is one of my first hardware/electronic projects, so please know that I'm trying my best, and some things may not be as polished...

Phones are always filled with distractions. If you want to check the time, you click on the screen of your phone, and then see a few notifications. You pick up the phone to check what's happening, and then an hour has disappeared. I wanted a simple device that is easy to carry around, and it should have some basic things like the time, a stopwatch, a timer (if possible), and more. Right now, I'm still doing the main desiging/researching and making the schematic for the pcb, but for now, this is a basic README.
